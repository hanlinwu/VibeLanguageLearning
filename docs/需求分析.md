一、	选题意义及国内外研究现状综述
1．选题意义
近年来，随着人工智能技术的快速发展，大语言模型（Large Language Models, LLMs）在自然语言处理领域展现出了显著优势，已逐渐成为语言学习辅助场景中的重要工具。越来越多的外语学习者开始在自主学习过程中依靠LLMs进行知识点查询、例句分析与练习生成，以期获得更灵活、更高质量的个性化学习支持。然而，现阶段看来，LLMs在这一任务中的表现暂时还未能充分满足实际应用中的种种需求。
LLMs在此任务中受到的核心限制之一在于缺乏稳定、跨会话的长期记忆能力。LLMs在连续交互中只能依赖有限的上下文窗口（context window）生成回复，难以自主存储、管理和调用学习者的历史学习行为、知识掌握程度以及学习习惯偏好等信息。因此，用户在每次交互前都必须重复提供大量背景信息，以确保模型生成的内容能够与其学习阶段相匹配。这造成了用户学习体验的显著碎片化与连续性不足，使其难以获得真正意义上个性化、阶段式的外语学习体验。
在使用大语言模型辅助语言学习的过程中，学习者往往需要反复向模型说明自身的当前掌握水平及练习需求；一旦提示不足，模型便容易忽略学习者的既有习惯与掌握水平，生成重复练习或难度不符合当前阶段的练习内容。此外，在知识提供环节中，LLMs仍可能出现内容错误或“幻觉”等情况，大大影响了辅助的可靠性与准确性。
基于上述背景，面向特定语言构建一个结合LLM与向量数据库、具备持续学习记忆与动态练习生成能力的个性化外语学习系统，不仅能够切实提升学习者的使用体验，也可为LLM长期记忆增强机制的研究提供具体实验场景与验证平台。

1. 国内外研究现状综述
本研究所关注的任务所面临的挑战大体可以按照系统的核心功能划分为两类：其一是知识点查询功能相关的问题，其二是动态出题功能相关的问题。
首先，在知识点查询方面，现有LLMs虽然能够提供基本的知识点与语法讲解，但其输出并不总是稳定可靠。由于现有通用模型并未特别关注语言学习方面的知识，且本身存在幻觉等固有风险，其在给出语法规则、例句用法或词汇解释时可能出现错误或不严谨之处，这会直接降低学习者对模型的信任。因此，仅依靠单一LLM难以满足稳定、精准、可控的知识查询需求。
其次，在动态出题功能方面，LLMs同样存在不足。自适应出题需要系统能够持续记忆学习者的做题表现、弱项分布与学习节奏，并基于这些信息动态调整题目难度与内容。然而，现有LLMs无法在跨会话的情况下自动保存这些关键数据，因此，其生成的练习很容易与学习者当前进度的脱节。例如，模型可能重复生成已练习过的内容，或突然给出难度过高的词汇与题目。这种不连贯性不仅降低学习效率，也会影响到学习者的学习体验与投入感。此外，LLMs在生成题目时缺乏稳定的题库约束，导致题型格式、难度区间和知识点覆盖常常存在不可预测性，从而难以形成系统性、循序渐进的练习路径。
在提升大语言模型的知识查询能力方面，现有研究主要从两个方向展开：参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）与知识增强（Knowledge-Augmented Generation）。在参数微调层面，Pfeiffer 等[1]提出的 AdapterHub 框架通过在 Transformer 中插入轻量化适配层，使模型能够以较低成本实现领域或任务适配，从而在特定应用场景中保持较高的一致性与稳定性。Hu 等[2]提出的 LoRA 方法进一步通过低秩矩阵分解实现高效微调，为大型模型的任务定制化提供了更灵活的技术路线。在此基础上，Lu 等[3]系统讨论了大模型的领域适配策略，验证了针对性微调在吸收专业领域术语体系与表达规律方面的有效性。与此同时，Lewis 等[4]提出的 RAG 框架通过将向量检索与外部知识库引入生成过程，为提升知识的可追溯性与减少幻觉提供了重要思路。此外，Lamsiyah 等[5]在教育场景中采用强化学习对大模型进行专项微调，证明了在知识讲解与题目生成任务中，通过定制训练可使模型输出更贴合学习需求。综上，这些研究构成了以参数微调实现领域与语种适配、以检索增强提升知识可靠性的技术路径，为构建个性化外语学习系统中的知识点查询模块提供了关键参考。
在动态出题功能方面，现有研究主要围绕大语言模型的长期记忆机制、个性化能力构建以及交互式学习策略展开。Park 等[6]提出的 Generative Agents 框架通过情境化的记忆流结构，使代理能够在开放环境中保持跨时段的一致行为，为构建可维护用户学习轨迹的长期记忆机制奠定了基础。随后，Shinn 等[7]的 Reflexion 方法引入了自我反思机制，使模型能够基于历史表现不断调整生成策略，展示了在交互式学习任务中利用元认知能力提升适应性的有效途径。此外，Zhong 等[11]提出的 MemoryBank 采用显式外部记忆模块，使大模型能够长期存储与检索用户相关信息，从而增强跨会话的一致性和行为延续性，为构建持续更新的学习档案提供了更工程化的解决方案。Gutierrez 等[8]的 HippoRAG 借鉴海马体记忆机制，实现了更稳健的长时信息存储与检索方式，为跨会话维护学习者知识状态提供了生物启发的技术路线。而在用户个性化能力方面，Magister 等[9]的工作展示了大模型学习并保持用户会话特征的机制，使模型能够在持续交互中形成稳定的用户画像；Yuan 等[10]进一步提出可演化条件记忆结构，使个性化记忆能够随用户知识状态与偏好动态更新，从而支持更细粒度的定制化交互过程。此外，Jia 等[12]与 Wu等[13]分别构建了长期记忆评测框架（如 Long-Term Memory Evaluation 与 LongMemEval），为大模型在跨会话场景中的记忆性能提供了系统化、可重复的测试基准。综上，这些研究从情境式记忆建模、反思式策略调整、显式外部记忆结构到神经启发的长期记忆机制、用户级个性化记忆构建及其评测方法，逐步形成了支持动态出题系统的关键技术基础，使大模型能够更加稳定地追踪学习者的知识水平、弱项分布与学习节奏，从而为实现自适应、个性化的语言练习生成提供了理论支撑。

二、选题研究目标和拟解决的关键性问题
（一）研究内容
1.	构建一个外语知识点查询模块（本研究中以法语为例），使系统能够通过检索增强技术，生成更加稳定、可追溯且符合法语语言规律的语法讲解和例句解释。
2.	设计一个能够跨会话运行的长期记忆机制，通过外部记忆库的方式记录学习者的学习进度、薄弱环节和学习习惯，从而确保系统能够在不同会话中准确检索并持续更新学习者的状态信息。
3.	实现一个自适应的动态出题系统，使系统能够在长期记忆机制和难度控制策略的支持下，生成符合学习者当前学习进度且能基本覆盖该阶段核心知识点的习题。
（二）研究目标
1.	本研究力图通过检索增强技术提升知识点讲解的准确性与前后一致性，为初学者提供可靠的语法与词汇知识。
2.	本研究旨在提升模型的跨会话长期记忆能力，使系统能够持续记录学习者的历史表现，形成可累积的学习档案，从而减少用户使用模型进行辅助时需要花费的沟通成本，提高学习效率。
3.	本研究期望生成具备自适应能力的语言练习，使系统能够根据学习者的掌握程度动态调整题目类型、知识点覆盖范围与题目难度，从而让学习过程更符合用户的个性化需求。
（三）拟解决的关键性问题
1.	本研究需要解决如何使大语言模型输出更加稳定可靠的法语知识点讲解的问题，包括减少幻觉、确保解释的逻辑连贯性，以及适配法语特有的语法结构等。
2.	本研究需要探索如何在跨会话环境中有效存储、检索与更新学习者信息，包括如何设计长期记忆结构、如何合理表示用户信息，以及如何平衡记忆的保持、遗忘与更新策略等问题。
3.	本研究还面临着如何确保动态出题逻辑与学习者当前水平相匹配的挑战，包括如何设计合理的难度分级体系、如何控制知识点覆盖度，以及如何确保题目生成的质量与多样性等问题。
4.	本研究还需应对工程实现中的多重要求，即如何在具体系统实现中兼顾模型性能与开发成本，确保整体架构与各模块协作方式能够支持良好的用户体验。

三、研究方案：拟采取的研究方法、技术路线及其可行性分析
（一）拟采取的研究方法
1.	检索增强技术的应用：本研究将采用检索增强生成（RAG）技术，将经过整理的基础语法与例句构建为向量数据库，并在生成阶段引入检索文档，以减少幻觉并提高讲解的可追溯性。
2.	基于外部记忆库的跨会话学习者建模：本研究将为用户构建结构化的长期学习档案，使用语义向量的方式记录学习者的表现、弱项与进度，并通过检索机制在新会话中调入相关记忆，使系统能够保持对学习者状态的连续理解，从而支持跨会话前后一致的交互体验。
3.	存在难度分级与知识点覆盖机制的自适应练习生成：本研究将构建小型难度分级体系及知识点标签系统，并将学习者的状态映射到生成提示词中，以引导模型在题目类型、题目难度与覆盖范围方面进行可控调整，从而生成符合学习者学习阶段的个性化练习内容。
（二）技术路线
1.	法语知识点模块构建与模型适配：本研究将整理法语初级语法体系，构建结构清晰的向量数据库，并将其接入RAG框架，使模型生成过程能够参考外部知识。
2.	长期记忆机制设计与跨会话信息管理：本研究将设计外部记忆存储结构，用于记录用户答题表现与知识掌握情况，并构建检索与更新策略，使每次会话都能根据历史记录追溯上下文，从而保持学习档案的连贯性与可用性。
3.	自适应出题模块与难度控制机制的实现：本研究将基于长期记忆中的学习者状态构建提示模板，通过难度分级策略与知识点标签体系引导模型生成多样化的练习。
（三）可行性分析
1.	本项目相关技术路径成熟且实现成本可控。RAG、向量数据库与外部记忆机制均为较为成熟的方法，已有完整的开源实现，使本研究能够在可控成本下完成系统搭建，并确保模型性能具有明确的可优化方向。
2.	本研究规模适中，适合本科毕业设计实施。本研究聚焦于法语初级场景，知识点体系明确，数据规模有限，且系统由两个主要功能模块构成，各模块之间逻辑独立但整体可集成，使任务复杂度适中。
3.	本研究的实验验证路径清晰，成果可量化评估。本研究的关键模块均可通过固定学习任务进行系统化验证，从而保证研究成果具有可观测性、可复现性和评估依据。
